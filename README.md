AI Hair & Scalp Analyzer

An AI-powered web application that analyzes scalp images to detect hair conditions and provide actionable insights.

*Features
- Multi-angle image upload (front, top, back)
- AI-based condition detection:
  - Androgenetic Alopecia
  - Dandruff
  - Healthy Hair
  - Scalp Disorders
- Severity estimation & risk scoring
- Personalized recommendations
- Interactive UI with real-time results
- 
*Tech Stack
- Frontend: React
- Backend: FastAPI
- AI: OpenAI API (Vision)
- Image Processing: Base64 encoding
- 
*How it Works
1. User uploads 3 scalp images
2. Backend processes images
3. AI analyzes patterns & conditions
4. Structured results returned
5. UI displays insights + risk level
   
*Note
This is an AI-assisted system and not a medical diagnosis.
